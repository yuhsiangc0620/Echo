# Candy Catalog

This folder is the source of truth for Echo candy types.

Edit `catalog.ts` when you want to change:

- MediaPipe audio class mapping
- candy display name
- candy CSS class / color
- trigger threshold
- whether the class can drop candy
- whether the class is a work, ambient, or quiet sound

The current candy visuals are still prototype-level. Names, shapes, and thresholds can be refined later without rewriting the app screens.
